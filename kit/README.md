# KURDISH DENT render kit
- `render_post.py spec.json out.jpg` — info image, styles: poster, cards, myth, bignum
- `render_reel.py spec.json out.mp4` — animated Reel with original music (`music.py`), CC0 SFX (`sfx/`, SFX Kit by Wyzowl, CC0) and optional Kurdish voiceover (`"voice": path`)
- Rabar font is stored encrypted (`Rabar_021.ttf.enc`); decrypt to `Rabar_021.ttf` before rendering.
